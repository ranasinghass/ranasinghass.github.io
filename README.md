Personal webpage / CV template for Suraj Sampath Ranasingha

Files added:
- index.html — single-page CV
- css/style.css — styles
- js/main.js — small interactive scripts

How to use:
1. Place your PDF CV at `files/Suraj_Sampath_Ranasingha.pdf` or update the link in `index.html`.
2. Replace placeholder texts (email, location, education, publications) in `index.html`.
3. Open `index.html` in a browser. Toggle theme with the button and use Print to save as PDF.

Development notes:
- This is a minimal, dependency-free static site. You can host it on GitHub Pages or any static host.
- To extend: add social links, external publications list, or microdata enhancements.
